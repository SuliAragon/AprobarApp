# Project Instructions

## Official Tests and Mock Exams

- Grade academy or official PDF questions using exactly the answer key supplied with that PDF.
- Never substitute an answer letter based on reasoning, external sources, or a suspected error. Changes require an explicit user request for that specific correction.
- Preserve the original option order and wording. Extraction repairs may restore missing text, but must retain the answer letter from the source key.
- Do not invent a factual explanation to justify a questionable key. State the answer assigned by the key neutrally, without reinterpreting the question or proposing another graded answer.
- If the answer key is unavailable, do not guess the correct answer.
